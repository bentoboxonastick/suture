# Suture Error Code Directory & Troubleshooting Guide

This directory maps every error code generated by Suture to its root cause and self-guided resolution steps.

---

## Error Code Matrix

| Error Code | Category | Description | Self-Guided Resolution |
| :--- | :--- | :--- | :--- |
| `ERR_DEBRID_EXPIRED` | Debrid / Streams | Debrid service token is expired or invalid. | Go to **Settings → Accounts → Debrid** and re-authenticate or renew your subscription. |
| `ERR_DEBRID_RATE_LIMIT` | Debrid / Streams | Debrid provider API rate limit exceeded. | Wait 30 seconds before requesting new streams; avoid spamming rapid stream requests. |
| `ERR_ADDON_MANIFEST_INVALID` | Addons | Stremio v3 addon manifest URL is invalid or unreachable. | Verify the addon URL syntax in **Settings → Addons** and ensure it ends with `manifest.json`. |
| `ERR_ADDON_MALFORMED` | Addons | Addon returned an invalid JSON response payload. | Contact the addon maintainer or remove the addon in **Settings → Addons**. |
| `ERR_STREAM_UNREACHABLE` | Video Player | Stream URL returned HTTP 404/500 or timed out. | Try selecting an alternative stream source from the stream picker list. |
| `ERR_STREAM_PLAYBACK_FAILED` | Video Player | Playback failed due to network disruption or unplayable stream container. | Select another stream source or open the stream in an external player (Infuse / VLC / IINA). |
| `ERR_EPG_PARSE_FAILED` | Live TV | XMLTV EPG feed is malformed or inaccessible. | Verify your EPG URL in **Settings → Live TV → Playlists** or re-download the guide. |
| `ERR_EPG_OUT_OF_SYNC` | Live TV | EPG broadcast times do not match local device clock. | Check that your device time zone is set to automatic and adjust EPG offset in settings if needed. |
| `ERR_M3U_UNREACHABLE` | Live TV | M3U playlist server is down or blocked. | Test the M3U link in a browser, check VPN settings, or contact your IPTV provider. |
| `ERR_CODEC_UNSUPPORTED` | Video Player | AVPlayer cannot decode video/audio format natively. | Enable **libmpv fallback engine** in **Settings → Playback** or use **Open in Infuse/VLC**. |
| `ERR_TIDAL_SESSION_EXPIRED` | Music | Tidal user OAuth session has expired. | Go to **Settings → Accounts → Tidal** and tap **Re-authenticate**. |
| `ERR_TRAKT_SYNC_FAILED` | Scrobbling | Trakt API returned an error during scrobble dispatch. | Check internet connection or re-link Trakt account in **Settings → Tracking**. |
| `ERR_CLOUDKIT_QUOTA` | iCloud Sync | User iCloud storage is full or restricted. | Free up space in iCloud settings or disable cellular data restrictions for iCloud Drive. |
