# Suture User Guide & Knowledge Base

Welcome to the **Suture** user documentation. Suture is a native media hub for Apple devices (macOS, iPadOS, iOS, and tvOS) that unites Shows, Movies, Live TV, and Music into a single Netflix-grade streaming experience.
