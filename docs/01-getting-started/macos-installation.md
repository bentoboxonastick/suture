# macOS Installation & Quick Start

Welcome to Suture on macOS! Suture provides a native, hardware-accelerated streaming experience on Apple Silicon and Intel Macs.

---

## 💻 System Requirements
- **macOS 15.0 (Sequoia)** or later.
- Apple Silicon (M1/M2/M3/M4) or 64-bit Intel Mac.

---

## ⚡ Keyboard Shortcuts

Suture on macOS features full keyboard navigation for zero-friction media control:

| Key | Action |
| :--- | :--- |
| `Space` | Toggle Play / Pause |
| `Left / Right Arrow` | Seek backward / forward 10 seconds |
| `Up / Down Arrow` | Adjust volume |
| `F` | Toggle Fullscreen |
| `M` | Mute / Unmute audio |
| `Cmd + F` | Instant focus on Universal Search |
| `Cmd + ,` | Open Settings & Addon Manager |

---

## 🚀 First-Time Configuration
1. Open Suture on your Mac.
2. Go to **Settings → Addons** to configure your personal open media catalogs or paste a custom Stremio v3 addon URL.
3. If you have an M3U IPTV playlist, import it in **Settings → Live TV**.
4. Enable **iCloud Sync** in Settings to automatically sync your library, settings, and watch states across your iPad, iPhone, and Apple TV.
